## Como reproduzir a verificação

```sh
docker compose up -d --wait postgres localstack
bun install --frozen-lockfile
bun run format:check
bun run test:all
bun run build
docker compose --profile test run --build --rm tests
docker compose up -d --build --wait --scale app=3
bun run demo
```

O runner usa nomes novos para banco e filas em cada execução e remove somente esses recursos ao terminar. PostgreSQL precisa permitir `CREATE DATABASE` na role de testes. A suíte contém 35 testes unitários e 23 de integração. Testes de concorrência e crash são testes de correção; não são um benchmark de carga.

## Escolhas permitidas e opcionais

- TypeORM foi escolhido dentre os ORMs aceitos.
- Autenticação foi omitida conforme autorização expressa da seção 2, com desenho OIDC externo e porta no código.
- O modelo suporta BRL, USD e EUR; o desafio permitiria restringir a BRL.
- Double-entry, OpenTelemetry, dashboard e teste de carga são opcionais e não foram implementados.
- A avaliação de produção exige os controles e procedimentos adicionais descritos na arquitetura.
